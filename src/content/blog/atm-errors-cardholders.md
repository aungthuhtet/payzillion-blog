ဒီနေ့ခေတ်မှာ ATM စက်တွေကြောင့် (24/7) ငွေထုတ်ဖို့ အဆင်ပြေလွယ်ကူသွားပေမယ့် စက်တွေ၊ စနစ်တွေ အပေါ်မှီခိုထားတာဖြစ်လို့ အမြဲတမ်း အဆင်ပြေနေမယ်လို့ မျှော်လင့်ထားလို့ မရပါဘူး။ Error တွေ issue တွေနဲ့လည်း တစ်ကွေ့မဟုတ်တစ်ကွေ့ တွေ့ရမှာဖြစ်ပါတယ်။ အဲ့ဒီအတွက် ဖြေရှင်းနည်းတွေ၊ ဆောင်ရန်ရှောင်ရန်တွေ ကြိုတင်ပြီး သိထားရင်တော့ စိုးရိမ်စရာမလိုဘဲ အသုံးပြုနိုင်မှာပါ။

ATM တွေမှာ အဖြစ်များတဲ့ ပြဿနာတွေကတော့…

**၁) စက်ထဲက ကဒ်ပြန်မထွက်လာတာ (Card Retained/Stuck)**  
ATM စက်ထဲကနေ ကဒ်ပြန်ထွက်မလာတာ ဖြစ်ပါတယ်။ ကဒ်စားတယ်လို့လည်း အလွယ်ပြောကြပါတယ်။ တစ်ခါတစ်လေမှာ Card Reader error ကြောင့်ဖြစ်စေ၊ စနစ် error ကြောင့်ဖြစ်စေ၊ မီးပျက်သွားလို့ဖြစ်စေ၊ သက်ဆိုင်ရာ ကဒ်ထုတ်ပေးထားတဲ့ (Card Issuer) ရဲ့ သတ်မှတ်ချက်ကြောင့်ဖြစ်စေ (ဥပမာ- ကဒ်ပျောက်တိုင်ထားတဲ့ကဒ်နဲ့ အသုံးပြုတဲ့အခါမျိုး၊ Fraud အဖြစ် သံသယရှိတဲ့အခါမျိုးမှာ) ATM ကနေ ကဒ်ပြန်ထွက်မလာတာ ဖြစ်နိုင်ပါတယ်။ ဘာကြောင့်ပဲဖြစ်ဖြစ် ATM မှာ ကဒ်စားသွားခဲ့ရင် အရင်ဆုံး ကဒ်ကို ယာယီ block တာမျိုး၊ ပိတ်တာမျိုး ချက်ချင်းလုပ်ပါ။ Mobile Banking app ကနေ ကိုယ်တိုင်လုပ်လို့ရရင် လုပ်ပါ၊ မရခဲ့ရင် သက်ဆိုင်ရာကဒ်ထုတ်ပေးထားတဲ့ ဘဏ်ကို ချက်ချင်းအကြောင်းကြားပြီး ကဒ် block လုပ်ခိုင်းပါ။ ပြီးတော့ ကဒ်စားခံရတဲ့ အကြောင်းကိုလည်း သတင်းပို့ပြီး ကဒ်အသစ်ပြန်ထုတ်ပေးဖို့ request လုပ်ပါ။ ဒီနေရာမှာ မြန်မာပြည်က ဘဏ်တွေမှာတော့ သက်ဆိုင်ရာ ATM ထဲကနေ ကဒ်ကို ပြန်ထုတ်ပြီး Cardholder တွေကို ပြန်ပေးတာမျိုးလည်း ဖြစ်နိုင်ပါတယ်။ Card security အတွက် အဲ့ဒါ အဆင်မပြေပါ၊ ဖြစ်နိုင်ရင် ကဒ်အသစ် ထုတ်ပေးဖို့သာ တောင်းဆိုသင့်ပါတယ်။ ကဒ်အသစ်ဆိုပေမယ့် ကဒ်နဲ့ချိတ်ထားမယ့် အကောင့်ကတော့ အရင်အကောင့်ကိုပဲ ချိတ်ဆက်ခိုင်းရမှာ ဖြစ်ပါတယ်။ ဘာလို့ ကဒ်အသစ်ထုတ်ပေးခိုင်းသင့်သလဲဆိုတော့ ကိုယ့်ရဲ့ ကဒ်နံပါတ်နဲ့ CVV နံပါတ်တွေကို ဘဏ်ဝန်ထမ်းတွေ သိသွားပြီဖြစ်တာမို့ ကဒ်အသစ်ထုတ်ခြင်းသည်သာ အကောင်းဆုံးဖြေရှင်းနည်း ဖြစ်ပါတယ်။ ဘဏ်ဝန်ထမ်းတွေကို အကြွင်းမဲ့ ယုံကြည်ပါ၊ သို့သော် ကဒ်ရဲ့အသေးစိတ် အချက်အလက်တွေကိုတော့ ကိုယ်ကလွဲပြီး ဘယ်သူ့ကိုမှ လုံးဝ ပေးမသိပါနဲ့။

**၂) ငွေထွက်မလာတာ (Cash Not Dispensed)**  
ATM စက်မှာ ငွေထုတ်တဲ့အခါ ထုတ်ယူမယ့် ငွေပမာဏကို ရိုက်ထည့်လိုက်ပြီးနောက် ငွေထွက်မလာတာဖြစ်ပါတယ်။ ကဒ်နဲ့ချိတ်ထားတဲ့ ဘဏ်အကောင့်ထဲကနေတော့ ငွေဖြတ်သွားပါတယ်၊ ဒါပေမယ့် ATM စက်ကနေတော့ ငွေထွက်မလာဘဲ error တက်တာမျိုးပါ။ ATM စက် error ကြောင့်ဖြစ်စေ၊ စက်ထဲမှာ ငွေကုန်သွားလို့ဖြစ်စေ၊ ATM Host ကြောင့် ဖြစ်စေ၊ Card Issuer သို့မဟုတ် Network ပြဿနာတစ်ခုခုကြောင့်ဖြစ်စေ ငွေထွက်မလာတာ ဖြစ်နိုင်ပါတယ်။ ပုံမှန်အားဖြင့် ATM စက်တွေမှာ ငွေထွက်မလာခဲ့ရင် ATM စက်ကနေ Card Issuer စနစ်ဆီကို ချက်ချင်း သတင်းပို့ပါတယ်။ Cardholder ရဲ့ ဘဏ်အကောင့်ထဲကို ငွေပြန်ထည့်ပေးဖို့ Auto Reversal message ပို့ပေးပါတယ်။ ၁မိနစ်ကနေ အများဆုံး ၃မိနစ်အတွင်းမှာ သက်ဆိုင်ရာ ဘဏ်အကောင့်ထဲကို ငွေပြန်ဝင်ပါတယ်။ အဲ့ဒါကြောင့် ATM စက်မှာ ငွေထုတ်မရတဲ့အခါမှာ ပထမဆုံး လုပ်သင့်တာက ATM မှာဖြစ်စေ၊ ကဒ် (ဘဏ်အကောင့်) နဲ့ ချိတ်ဆက်ထားတဲ့ mobile banking ကနေဖြစ်စေ ငွေဖြတ်သွားပြီး ပြန်ဝင်လာသလား (Balance) စစ်ကြည့်ရမှာပါ။ အကယ်၍ ပြန်မဝင်လာခဲ့ရင်တော့ သက်ဆိုင်ရာ ကဒ်ထုတ်ပေးထားတဲ့ဘဏ်ကို Transaction ID ၊ အချိန်နဲ့ ATM တည်နေရာကို ပြောပြီး အကြောင်းကြားပါ။ အဲ့ဒါဆိုရင် သက်ဆိုင်ရာဘဏ်က လိုအပ်တဲ့အချက်အလက်တွေကို စစ်ဆေးပြီး ငွေပြန်ထည့်ပေးပါလိမ့်မယ်။ ငွေပြန်ရဖို့ ရက်အနည်းငယ်ကနေ တစ်ပတ်လောက်အထိ စောင့်ရတာမျိုးဖြစ်နိုင်ပါတယ်။ ကဒ်ထုတ်ပေးထားတဲ့ ဘဏ်ရဲ့ ATM မှာ ပြဿနာဖြစ်တာဆိုရင်တော့ ငွေမြန်မြန်ပြန်ရနိုင်ပါတယ်၊ အခြားဘဏ်ရဲ့ ATM မှာဆိုရင်တော့ စစ်ဆေးရမယ့် process တွေ ပိုများလာမှာမို့ နည်းနည်းစောင့်ရတတ်ပါတယ်။

**၃) ငွေပမာဏ မှားယွင်းပြီး ထွက်တာ (Wrong Amount Dispensed)**  
ဥပမာ- ငွေ ၅၀,၀၀၀ ထုတ်တာကို ၁သောင်းတန် ၅ရွက် ထွက်မလာဘဲ၊ ၅,၀၀၀ တန် ၅ရွက်ပဲ ထွက်လာပြီး ၂၅,၀၀၀ ပဲ ရတာမျိုပါ။ အကယ်၍ အဲ့ဒီလို ဖြစ်လာခဲ့ရင် သက်ဆိုင်ရာဘဏ်ကို ချက်ချင်းအကြောင်းကြားပါ။ ဖြတ်ပိုင်းနဲ့ ထွက်လာတဲ့ ငွေကိုလည်း အ‌ထောက်အထားအနေနဲ့ ဓာတ်ပုံရိုက်ယူထားပါ။ အဲ့ဒါဆို သက်ဆိုင်ရာဘဏ်က ATM Log နဲ့ CCTV record တွေကို စစ်ဆေးပြီး လိုအပ်တဲ့ငွေကို ပြန်ပေးပါလိမ့်မယ်။ အကယ်၍ ကိုယ်က ငွေ ၅၀,၀၀၀ ထုတ်တာကို ၁၀,၀၀၀ တန် ၁၀ရွက်ထွက်လာပြီး ငွေ ၁၀၀,၀၀၀ ရတာမျိုးဖြစ်ခဲ့ရင်လည်း ဘဏ်ကို အကြောင်းကြားသင့်ပါတယ်။ ကိုယ်က ငွေပိုရတာဖြစ်ပေမယ့် အချိန်တန်လို့ ဘဏ်က ငွေစာရင်းစစ်ဆေးတဲ့အခါ ဘယ် cardholder တွေဆီ ငွေပိုထုတ်ပေးမိသလဲ အဖြေပေါ်မှာဖြစ်လို့ ကိုယ်ရိုးသားကြောင်းကို ဘဏ်ကို အရင်အသိပေးခြင်းဖြင့် မဏ္ဍပ်တိုင် တက်ပြလို့ရပါတယ်။ (စိတ်ဝင်စားရင် "ATM: Er Rak Error" ဆိုတဲ့ ထိုင်းကားလေးကို ရှာကြည့်ကြည့်ပါ။ ရုပ်ရှင်ထဲကအတိုင်း လက်တွေ့မှာလည်း ဖြစ်နိုင်ပါတယ်နော်။)

**၄) ကွန်ရက်ပြဿနာ၊ စက်/စနစ် ပြဿနာ (Network Failure, ATM Device Error)**  
ATM စက်တွေမှာ တစ်ခါတစ်ရံ Timeout ဖြစ်နေပြီး လိုင်းမတက်တာ၊ အသုံးပြုနေရင်း လိုင်းကျသွားတာ "Connection Error" လို့ ပြတာမျိုးတွေ ဖြစ်တတ်ပါတယ်။ ATM Host ဘက်မှာ ပြဿနာရှိတာ ဖြစ်နိုင်သလို၊ ATM စက်မှာ ပြဿနာရှိနေတာလည်း ဖြစ်နိုင်ပါတယ်။ အဲ့ဒီလိုဆိုရင်တော့ ခဏစောင့်ပြီးမှ ထပ်ကြိုးစားကြည့်ပါ။ မရခဲ့ရင် အခြား ATM စက်မှာ သွားပြီး အသုံးပြုပါ၊ သို့မဟုတ် သက်ဆိုင်ရာ ဘဏ်ကို ဖုန်းဆက်ပြီး ATM စက်ချို့ယွင်းနေတာကို တိုင်ကြားပေးလိုက်ပါ။ အဲ့ဒါဆို သက်ဆိုင်ရာဘဏ်က အမြန်ဆုံး ဖြေရှင်းပေးပါလိမ့်မယ်။ တစ်ခါတစ်ရံ ATM Host ဘက်ကနေ network ပေါ်က ဖြေရှင်းပေးလိုက်ရုံနဲ့ အဆင်ပြေသွားနိုင်သလို၊ တစ်ခါတစ်ရံ ATM Service Team ကို လွှတ်ပြီး လူကိုယ်တိုင်လာပြီး ဖြေရှင်းပေးဖို့ လိုအပ်တာလည်း ဖြစ်နိုင်ပါတယ်။ အလျင်လိုနေခဲ့ရင် ဘဏ်ကို အကြောင်းကြားတဲ့အခါမှာ အနီးစပ်ဆုံး အသုံးပြုလို့ရမယ့် ATM စက်တည်နေရာကို မေးပြီး အဲ့ဒီစက်မှာ သွားပြီး အသုံးပြုတာမျိုးလုပ်ပါ။
