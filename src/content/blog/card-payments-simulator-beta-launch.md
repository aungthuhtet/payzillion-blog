ဖေဖော်ဝါရီ ၁၃ရက်နေ့က ကြေငြာထားတဲ့အတိုင်း PayZillion ရဲ့ Educational Card Payments Simulator ကို launch လုပ်ထားပြီး ဖြစ်ပါတယ်။ ၁၀၀% အခမဲ့ အသုံးပြုနိုင်ပြီး [https://simulator.payzillion.com/](https://simulator.payzillion.com/) ကနေ ဝင်ရောက် အသုံးပြုနိုင်ပါတယ်။

အသုံးပြုဖို့အတွက် test card တွေ အပါအဝင် လိုအပ်တဲ့ အရာအားလုံး simulator ထဲမှာ setup လုပ်ထားပြီး ဖြစ်ပါတယ်။ ကွန်ပြူတာ၊ တက်ဘလက်၊ ဖုန်း နှစ်သက်ရာ device အားလုံးကနေ အသုံးပြုနိုင်ပြီး Web Browser နဲ့ Internet ရှိရင် ရပါပြီ။

Simulator က self-contained educational sandbox ဖြစ်ပါတယ်။ ပြင်ပက ဘယ် system၊ ဘယ် card network တွေနဲ့မှ ချိတ်ဆက် မထားပါဘူး။ Sandbox ထဲမှာရှိသမျှ အရာအားလုံးက dummy data တွေသာဖြစ်ပြီး လက်တွေ့နဲ့ အနီးစပ်ဆုံးဖြစ်အောင် တည်ဆောက်ပေးထားပါတယ်။

အခု တင်ပေးထားတာက beta version ဖြစ်ပြီး စမ်းသပ်အသုံးပြုလို့ရအောင် တင်ပေးထားတာပါ။ Logic ပိုင်းနဲ့ ISO 8583 message တွေ ပြန်စစ်ပြီး မတ်လ ပထမပတ်လောက်မှာ version 1 ကို release လုပ်ပေးပါမယ်။ Version 1 ထွက်တဲ့အခါကျရင်လည်း အခုလိုပဲ အခမဲ့ အသုံးပြုလို့ရမှာဖြစ်ပြီး feature အသစ်တွေလည်း ထပ်ပါလာဖို့ရှိပါတယ်။ စမ်းသုံးကြည့်ပြီး လိုအပ်တဲ့ Feedback တွေလည်း report တင်ထားလို့ ရပါတယ်။

ဘာလို့ ဒီ simulator ကို လုပ်ရသလဲဆိုရင် card payments ကို လေ့လာချင်တဲ့သူတွေအတွက် အလွယ်တကူ အသုံးပြုနိုင်တဲ့၊ အခမဲ့ရတဲ့၊ ပြီးတော့ real world မှာ ATM, POS, eCommerce တွေ အသုံးပြုရသလို realistic user experience ကိုလည်း ပေးတဲ့ tool တစ်ခု create လုပ်ဖို့ စဉ်းစားမိရာကနေ စလုပ်ဖြစ်ခဲ့ပါတယ်။

PayZillion — Educational Card Payments Simulator မှာ ဘာတွေလုပ်လို့ရမလဲဆိုတော့ အဓိက လုပ်ဆောင်ချက် (၅) ခု ရှိပါတယ်။

(၁) ATM, POS နဲ့ eCommerce အစရှိတဲ့ Channel တွေကနေ Transaction တွေကို လက်တွေ့ real-world  မှာ အသုံးပြုရသလို စမ်းသပ်နိုင်မှာ ဖြစ်ပါတယ်။

(၂) Transaction လုပ်လိုက်တိုင်းမှာ Terminal ကနေ ပို့လိုက်တဲ့ Request နဲ့ Issuer ဆီက ပြန်လာတဲ့ Response တွေရဲ့ ISO 8583 Message Log တွေကို လေ့လာနိုင်မှာ ဖြစ်ပါတယ်။

(၃) စမ်းလိုက်တဲ့ Transaction တစ်ခုချင်းစီအတွက် Live Transaction Flow အဆင့်ဆင့်ကိုလည်း Visual animation နဲ့ ကြည့်လို့မှာ ဖြစ်ပါတယ်။

(၄) စမ်းသပ်ခဲ့သမျှ Transaction History တွေကို Card Host/Switch တွေမှာ မြင်ရသလို monitoring လုပ်လို့၊ စစ်လို့ရမှာ ဖြစ်ပါတယ်။

(၅) Card Management module လည်း ပါလို့ လက်တွေ့မှာ card control တွေကို Card Management System တွေမှာ ဘယ်လိုထိန်းချုပ်ကြသလဲဆိုတဲ့ သဘောတရားကိုလည်း လေ့လာနိုင်မှာ ဖြစ်ပါတယ်။
